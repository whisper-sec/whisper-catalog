# Security

This repository publishes the **whisper.security query catalog**: curated, read-only
graph queries and their metadata. It contains no code that runs against your systems
and no secrets.

The graph endpoint (`https://graph.whisper.security/api/query`) is a **keyed** surface.
Never commit your API key. Treat it as a secret.

Report a security concern with the catalog or the Whisper platform to
**security@whisper.security**.
